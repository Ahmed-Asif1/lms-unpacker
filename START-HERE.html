01 / Get going

Open the launcher. That’s it.

You don’t need a terminal command, an account, or a separate installation.

1

Open the desktop app

Double-click LMS-Unpacker.exe. It can live in Downloads, on your desktop, or anywhere convenient. No supporting files to arrange.

2

Browse or drop

Use Choose folder or Choose ZIP. Or drag one folder or ZIP into the window. Select the folder containing your courses to process them together.

3

Preview, then apply

Choose a task and click Preview changes. Review destinations and matching reasons, then click Apply changes. Changing a setting requires a new preview.

OPEN IT NEXT TIME

One place in your Start menu

Open App → App settings → Add to Start menu. It saves its own copy in your user account and creates a shortcut. Then search Start for LMS Unpacker. You can remove the original download.

Remove shortcut removes the Start entry. To remove the app copy too, close it and delete %LOCALAPPDATA%\Programs\LMS Unpacker. No administrator account is needed.

IF DOUBLE-CLICK DOES NOT WORK

A command you can paste

In File Explorer, open the folder containing the EXE. Click the address bar, type powershell, and press Enter. Paste:

& ".\LMS-Unpacker.exe"

For the terminal edition, use .\LMS-Unpacker-CLI.exe --help. See all launch alternatives, including the source BAT.

You can keep the EXE inside your Courses folder: it looks for ZIPs there and one course-folder level below. Or choose materials elsewhere. Folder and ZIP pickers remember their own last locations, even before you extract anything. Results stay beside each ZIP unless you choose another output folder.

Know what “skip” means. If a filename already exists, the incoming version is skipped even when its content differs. The ZIP is then deleted after success. Choose Extraction options → Rename to keep both versions, or enable Keep ZIP to retain the archive.
Let the app find your downloads

Put it beside your courses. See what it finds.

Discovery lists ZIP names and sizes in the background. It does not open or extract them. Use Preview to validate their contents, then Apply when the plan looks right.

1
Where startup looks
An explicit folder or ZIP passed to the app wins. Otherwise, the portable app checks beside the actual EXE first. If it finds no ZIPs there, it tries your remembered location. Its temporary supporting files are never the starting folder.
2
Pickers that stay nearby
On a fresh setup, both Choose folder and Choose ZIP start beside the EXE. Folder and ZIP choices are remembered separately after you select them. A remembered folder that no longer exists falls back to the app folder. The source-script edition starts from its working directory.
3
New ZIPs after launch?
Click Rescan to refresh the ZIPs found tab, or Use app folder to return beside the EXE. Select rows and use Use selected ZIPs to process only those archives. Changing the input requires another preview.


One level means one level. The app scans ZIPs directly inside Courses and directly inside its immediate course folders. It excludes deeper folders, links, hidden folders and known working folders such as Lab, submission and templates. To process one of those folders, explicitly select it. The same scan scope is used for discovery and extraction.






Find the right control
A quieter desktop, with help when you need it.
Choose a task and review the ZIP retention notice. Advanced settings stay in expandable sections. Hover a control for an explanation; keyboard users can also open the sections and read the guide below.


LEFT / YOUR SETTINGS
Start with the task
Flatten removes LMS wrapper folders. Just unzip keeps the original folder structure. Organization tasks reveal course and lecture-grouping controls.
Extraction options contains conflicts, scan depth and ZIP output. The Workspace tab holds Saved workspaces and Additional inputs. The App tab holds optional Start menu installation. These occasional choices stay out of the Task tab.
RIGHT / YOUR RESULTS
Found → Preview → Done
ZIPs found shows archive filenames. Preview shows planned destinations and content conflicts. Select a preview row, then open File details for its full paths, incoming size and hash comparison. Activity contains errors and undo previews.
The progress panel names the current phase and file. Its bar measures that phase, so it can restart for another ZIP. The completion panel stays visible and reports skipped files and ZIP deletion. Open result folder takes you to the output.






Saved workspaces versus additional inputs
A workspace remembers a folder, queue, task, profile, grouping, output and retention settings. It does not duplicate documents. Name the setup and click Save workspace. Select its name next time; saving the same name updates it. Hover an item to inspect its details. A queue is the ordered list of inputs for one run. A single Courses folder normally needs no queue because its immediate course folders are already scanned.


Existing filenames: Skip, Rename and identical content
Skip is the default and preserves the existing filename even if incoming content differs. A SHA-256 comparison distinguishes identical content from different content, including collisions between queued inputs. Rename creates numbered names for different versions. Identical matching content is skipped under either policy. Successfully processed ZIPs are deleted by default even when incoming content was skipped; Keep ZIP retains the archive.


Output folder and original ZIP structure
Leave ZIP output blank to write beside each archive. Choose a folder to send ZIP contents elsewhere. With Just unzip, each archive still gets a folder named after the ZIP and its internal structure stays intact. Course routing still applies in an organization task. Loose documents are organized in place, with an undo record; the ZIP output option does not move them to another drive.


Week or topic when filenames do not mention a week
A profile can match a filename to a syllabus week or topic. You can create it in Edit courses and syllabus or import CSV. Choose By topic for useful named groups without inventing dates. Uncertain week mappings stay Unscheduled; missing topic mappings stay Unsorted topics. Check the Why column and the Calculus example below before applying.


Why is Apply disabled? Why is Add rule hidden?
Apply needs a successful preview with something to process. Changing paths, task settings or queue order invalidates the old preview. Add rule is available for organization tasks after a preview file is selected; it stays out of the basic unzip view. Errors are shown in Activity. ZIP discovery alone does not enable Apply because it has not validated archive contents.


Progress, cancellation and history / undo
Cancel safely stops at a safe boundary. Completed operations remain; an already processed ZIP may already be deleted. Unprocessed archives are kept. Preview again before continuing. History / undo can restore loose documents moved by organization if their contents and original locations still pass validation. It cannot recreate deleted ZIPs or reverse extraction.


Keyboard navigation and hover tooltips
Use Tab and Shift+Tab to move between controls, Enter or Space to activate, and arrow keys to choose tasks or saved workspaces. Expand a section to reach its settings. The queue supports Delete to remove an entry without deleting files. Alt+Y focuses the input path, Alt+F chooses a folder, Alt+Z chooses ZIPs, Alt+P previews and Alt+A applies when enabled. Detailed control help is also exposed as accessibility help text; screen-reader behavior still depends on the reader and requires manual acceptance testing.








Make the next download easier
Set it up once. Reuse it next week.
Your folders can stay where they are. Save your setup, review unknown files and process a queue in one visit.




1
Choose your destinations
Pick multiple ZIPs or drop folders and ZIPs. The Workspace → Additional inputs section lists queued inputs. Set ZIP output folder if extracted files should go elsewhere; leave it blank for the current location. Loose documents stay in place with undo.


2
Teach it your courses
Choose an Organize task, then Edit courses and syllabus. Add course codes and folders on the Courses tab. On Syllabus rules, try BIO-101 | *cell* | Lectures/Week 02 | Cell biology. Save a validated profile copy.


3
Review, then remember
Preview, enable Only unclassified, and select a file. Add rule for selected file opens a reusable rule you can edit. Save and preview again. Name and save a workspace to remember paths, profiles, queue and settings. During extraction, watch the current file, phase, ZIP count and elapsed time. When it finishes, the Done panel reports the outcome and lets you open the result folder. Errors and cancellation have their own messages.
Use Up / Down, Make first and Remove to edit the queue. The first input wins when names collide under Skip. Check Content comparison and File details before applying: different incoming content is still skipped and its successfully processed ZIP is deleted by default. Choose Rename or Keep ZIP if you need to retain it.


Need to stop? Click Cancel safely. The current read or archive publication finishes at a safe boundary. Completed work remains, including deletion of ZIPs already processed. Unprocessed ZIPs are kept. Preview again to continue.


Use the Linux CLI
Download LMS-Unpacker-CLI.sh and install PowerShell 7 (pwsh) using Microsoft's instructions linked in the README. No supporting app files are needed. In a terminal:
bash LMS-Unpacker-CLI.sh -Path "$HOME/Courses" -DryRun
bash LMS-Unpacker-CLI.sh -Path "$HOME/Downloads/course.zip" -Mode Extract -OutputPath "$HOME/Courses"
The first command previews. The second extracts and deletes the ZIP after success. Add -KeepZip to retain it. The graphical desktop is Windows-only.

05 / A few useful answers
Before you apply.


What if I just want an unzipper?
Choose Just unzip (task 2 in the CLI). The app preserves the ZIP’s internal folders inside a folder named after the ZIP. No course profile or organization is required. This is also the right mode for programming projects and files with links that rely on their folder structure.


What does the preview change?
Nothing. It reads archives to check their contents and shows the planned actions. It creates no extracted files, folders or undo logs. In the desktop, click Apply changes only after reviewing. In the CLI, answer Y to apply, or press Enter to cancel. Existing-document previews avoid reading document contents unless a collision needs comparing.


Will it touch my labs and submissions?
It scans loose documents in the selected folder and immediate course folders, not all nested directories. Known working folders such as Lab, submission, templates and evidence are excluded from that one-level scan. If you explicitly select a working folder, you are selecting its contents for processing. Choose Customize → scan 0 for only the selected folder.


Can I undo it?
You can undo existing-file organization using History / undo in the desktop (task 5 in the CLI) to choose a record from the folder you organized. You can also browse for the JSON record shown after the run. Undo also previews before restoring. The record lives under .lms-unpacker/history in your selected folder. Undo stops if files have changed or their old locations are occupied. It cannot restore deleted ZIPs or reverse extraction or overwrite. ZIP deletion is permanent, not a Recycle Bin operation.


How do I keep different versions of the same filename?
Choose Settings → Customize → Conflict choice 2, Rename. Different files become names like Lecture_1.pdf. Identical files at a matching destination are skipped. If you want to keep the source archive too, answer Y to Keep ZIP.


I get an error or “No ZIP files found.”
Check the selected path and scan depth. The desktop and CLI EXEs need no supporting files. Use Organize loose documents only for already-extracted materials. An extraction error keeps the affected ZIP; some files may already have been written if publishing failed. Close documents that are locked by another application, resolve the reported issue, and try again.


Why does Windows show a script or security message?
The launcher runs local PowerShell scripts and the release is unsigned. Use a copy you trust. Managed computers may restrict scripts; follow your institution’s policy. The launcher does not need administrator access and does not permanently change your account’s execution policy. See the README for supported systems and troubleshooting.


Can I use this guide offline and with a keyboard?
Yes. This HTML file contains its own styles and interactive examples. It has no fonts, analytics or other network dependencies. Use Tab to move between controls, Enter or Space to activate buttons, and arrow keys in the grouping selector. The app’s menu accepts typed numbers followed by Enter. Browser zoom and reduced-motion preferences are supported.
